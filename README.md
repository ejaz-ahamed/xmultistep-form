# XMultistep Form

Multi-step subscription form built for the Crio.Do XMultistep Form buildout.

**Live site:** see the Vercel deployment linked in this repo's About section.

## Features

- Four steps (personal info, plan, add-ons, summary) plus a thank-you screen
- Go back to any earlier step to change selections; "Change" link on the summary jumps to the plan step
- Monthly / yearly billing toggle that updates plan, add-on and total prices
- Validation for missing fields, badly formatted email, and a plan that hasn't been chosen
- Responsive layout with a mobile step indicator and fixed bottom navigation
- Hover and focus states on all interactive elements

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and Grid
- Vanilla JavaScript
- Deployed on Vercel
